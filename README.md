# 🎵 Auto-Song-PPTX（自動製作詩歌投影片）

寫一個純文字檔 `lyrics.txt`，一次過生成**多首**詩歌的 PowerPoint：自動分頁、自動加背景圖、自動在右下角加上段落跳轉按鈕（主歌／副歌一按即跳）。

---

## 一、先決條件

- 🖥️ Windows 電腦（本工具是 VBScript，Mac 用不到）
- 📊 已安裝 Microsoft PowerPoint 桌面版（網頁版不行）

> [!IMPORTANT]
> 執行前請先**儲存所有 PowerPoint 檔案**。若偵測到有未儲存的簡報，程式會停止並要你先儲存，不會強行關閉。

## 二、安裝（只做一次）

在 GitHub 按 **Code → Download ZIP**，解壓縮。以下檔案必須**放在同一個資料夾**：

```
create-lyrics-ppt.vbs   ← 主程式
lyrics.txt              ← 你要編輯的歌詞檔
background.jpg          ← 後備背景圖
background-1.jpg        ← 可選：編號背景圖
background-2.jpg        ← 可選：編號背景圖
```

> [!IMPORTANT]
> `lyrics.txt` 必須以 **UTF-8** 編碼存檔，否則中文變亂碼。記事本：另存新檔 → 編碼選 UTF-8。

## 三、`lyrics.txt` 怎樣寫

每首歌的格式：**歌名 → 字體大小 → 字體顏色 → 段落與歌詞**。

```
[在祢沒有難成的事]
60pt
dark blue

=1=
芥菜種的信心 可以將大山挪開
相信神的應許 可以跨越困難
==
信心的禱告 神都聽見
大聲地宣告 勇敢向前

=C1=
在祢沒有，沒有難成的事，
軟弱和憂慮中，祢不曾放棄我
```

想加第二首？直接接落去寫另一個 `[歌名]` 就得，**無上限**。

### 四個符號，記住就夠

| 符號 | 意思 | 效果 |
|---|---|---|
| `[歌名]` 或 `【歌名】` | 一首新歌開始 | 生成一個獨立的 `歌名.pptx` |
| `=1=` `=C1=` `=BRIDGE=` | 段落開始 | 開新一頁 ＋ **右下角加一個跳轉按鈕** |
| `==` | 分頁 | 開新一頁，**不加按鈕**（同段太長時用） |
| 空白行 | 無作用 | 只是方便你閱讀 |

> [!TIP]
> 按鈕文字 = 你在 `= =` 之間寫的字，會自動轉成**大寫**。所以 `=c1=` 與 `=C1=` 出來的按鈕都是 `C1`。當前所在那一頁的按鈕會**變黃色**highlight。

### 字體大小

歌名下一行，寫 `60pt` 或 `60` 都可以。

- 不寫 → 預設 **42pt**
- 範圍限制 **8 至 120**，超出會自動夾回

### 字體顏色

大小下一行。三種寫法任揀：

| 寫法 | 例子 |
|---|---|
| 英文顏色名 | `dark blue`、`red`、`purple`、`gold` |
| 十六進位 | `#FF0000` 或 `FF0000` |
| RGB 數值 | `255,0,0` |

可用顏色名（大小寫、空格都不理）：
`black` `white` `red` `darkred` `crimson` `green` `lime` `darkgreen` `blue` `darkblue` `navy` `yellow` `gold` `orange` `purple` `indigo` `violet` `magenta` `pink` `hotpink` `cyan` `teal` `aqua` `brown` `maroon` `olive` `gray` `silver` `lightgray` `darkgray` `coral` `salmon` `skyblue` `turquoise`

> [!WARNING]
> 打錯顏色名**不會報錯**，會靜靜變回黑色。想穩陣就用 `#RRGGBB`。

> [!NOTE]
> 字體大小與顏色兩行都可以省略。程式見到那行是 `=段落=` 或 `==` 就當歌詞正式開始。

### 🚨 標點符號會消失

> [!CAUTION]
> 歌詞中的**標點符號會被自動換成兩個空格**（中英文標點、括號、引號、破折號全部計）。這是投影用的排版慣例，**不是 bug**。
> 上面例子 `在祢沒有，沒有難成的事，` 出來會變成 `在祢沒有  沒有難成的事`。
> 👉 例外：`=` 不受影響，所以段落標記安全。

## 四、背景圖規則

每首歌找背景圖的順序（支援 `.gif` `.jpg` `.jpeg` `.png`）：

1. 🥇 **同名圖片** —— 歌名叫 `[恩典之路]`，就找 `恩典之路.jpg`
2. 🥈 **你選的編號背景** —— 執行時會彈窗問你用哪個 `background-<數字>`
3. 🥉 **`background.jpg`** —— 上一步留空／取消就用它
4. ⬜ 全部都無 → 純白背景

> [!TIP]
> 背景圖會自動加一層 **25% 白色半透明**，令歌詞看得清楚。

> [!NOTE]
> 背景圖只放在**投影片母片**上，不是每頁一張。所以事後想換背景：開啟 pptx → **檢視 → 投影片母片** → 換掉那張圖 → 全部頁面即時更新。
> 動畫 GIF 會原圖保留（動畫不會失效）；其他格式會自動壓縮至 150 ppi 減細檔案。

## 五、執行（3 步）

### 第 1 步：雙擊 `create-lyrics-ppt.vbs` ▶️

> [!NOTE]
> 會先彈出「執行前檢查通過」的訊息，按確定繼續。若用雙擊方式執行，之後還會多彈兩個小視窗顯示「資料夾」和「找到歌曲數」——**按確定跳過即可，屬正常**。
> 嫌煩可改用命令提示字元執行：`cscript //nologo create-lyrics-ppt.vbs`

### 第 2 步：選背景編號

若資料夾內有 `background-1.jpg`、`background-2.jpg` 等，會彈窗列出可用編號叫你揀。

- 輸入編號（例 `2`）→ 全部歌用 `background-2`
- **留空或按取消** → 改用 `background.jpg`
- 輸入不存在的編號 → 會叫你重新輸入

### 第 3 步：等完成 ✅

完成會彈窗告訴你建立了幾多個檔案。

## 六、你會得到什麼

同一個資料夾內，**每首歌一個 pptx**，檔名 = 歌名：

```
在祢沒有難成的事.pptx
我用信心抬起頭.pptx
```

每頁包含：

- 📝 **歌詞**：微軟正黑體、粗體、靠左、由上而下排
- 🏷️ **左下角小字**：`歌名 段落名`（例：`在祢沒有難成的事 c1`）
- 🔘 **右下角按鈕**：所有段落的跳轉按鈕，當前段落為黃色

投影片尺寸固定 **960 × 540 pt（16:9）**。

> [!CAUTION]
> **同名檔案會被直接刪除並重建，不會提示。** 若你手動改過生成的 pptx，記得先改名或搬走，否則下次執行會被覆蓋。

## 七、常見情況

| 情況 | 結果 |
|---|---|
| 歌名冇用 `[ ]` 或 `【 】` 包住 | 報錯「找不到歌曲」，整個程式停止 |
| 某首歌完全冇 `=段落=` 標記 | 彈窗指出該首歌名，**跳過它**，其餘歌繼續生成 |
| 歌名含 `\ / : * ? " < > \|` | 檔名中那些字元自動變成 `_` |
| `lyrics.txt` 空白 | 報錯停止 |
| 找不到 `lyrics.txt` | 報錯停止 |

> [!NOTE]
> 執行完會自動關掉它自己開的隱形 PowerPoint、清走殘留的 `~$` 鎖定檔。**你自己開著的 PowerPoint 視窗不會被動。**

## 八、🔐 VBS 與安全

VBS（VBScript）是 Windows 內建的自動化腳本檔。本工具只有一個：`create-lyrics-ppt.vbs`

### 查看或修改

> [!WARNING]
> 檢閱 `.vbs` 時**不要直接雙擊**，Windows 會立即執行它。

1. 在 `.vbs` 檔案按右鍵。
2. 選 **開啟檔案方式**。
3. 選「記事本」、Notepad++ 或其他文字編輯器。
4. 修改前先備份原始檔。
5. 修改後先在測試資料夾試跑，確認正常才正式使用。

### 用 AI 檢查安全性

如你不確定 script 是否安全：

1. 用記事本開啟 `create-lyrics-ppt.vbs`。
2. 複製全部程式碼。
3. 貼到你信任的 AI，並輸入：

```text

請列出它會讀取、建立、修改或刪除的檔案和資料夾。

```

> [!CAUTION]
> 不要把密碼、API Key、個人資料、教會內部資料或完整電腦路徑貼到公開 AI 對話。
